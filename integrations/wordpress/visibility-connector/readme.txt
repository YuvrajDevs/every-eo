=== Visibility Connector ===
Requires at least: 6.0
Tested up to: 6.6
Requires PHP: 7.4
Stable tag: 0.1.0
License: GPLv2 or later

Applies fixes from your Visibility audit: structured data (JSON-LD), meta descriptions, and AI-crawler access in robots.txt.

== Description ==
Fixes are stored in one option and applied through WordPress hooks at render time. Nothing edits your theme or post content. Remove a fix from the dashboard, or deactivate the plugin to remove all of them.

With Yoast SEO active, structured data is merged into Yoast's schema graph and meta descriptions are written to Yoast's own field.

A physical robots.txt file in your web root bypasses WordPress; the plugin reports this and can't change it.
